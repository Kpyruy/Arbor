# Arbor project instructions

## TaskNotes progress

For Arbor development, fixes, task reviews, verification and handoffs, read and
follow `.agents/skills/arbor-tasknotes-progress/SKILL.md` before starting the
scoped work. Keep its TaskNotes task up to date at work boundaries, not only
at the end of the turn. Pure read-only questions don't require task mutations.

This requirement applies only to Arbor. The main Obsidian vault is the progress
source; don't use the closed Niiga test vault as a tracking fallback.
